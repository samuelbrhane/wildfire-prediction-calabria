# Data

This folder contains all data used by the pipeline. It is divided into two subfolders: `raw/` for input data and `processed/` for all outputs generated by the preprocessing pipeline.

---

## Important Notes

**The warning zone shapefile and the processed dataset are included in the repository.** This means the model training, feature importance, and result plotting notebooks can be run directly after cloning, without running the preprocessing pipeline first.

**The original raw dataset is private and large.** The full `.h5` climate and fire target files live on a remote server and are not included here. They are only required to re-run the preprocessing pipeline. Access is restricted to authorized collaborators — contact the repository owner for details.

**The cleaned processed data** (`zone_sequence_merged.csv`) is a derived CSV included for review and reproducibility purposes. For any broader reuse, permission from the data owner is required.

## What Is Included

The following are committed to the repository and require no manual setup:

- `raw/WarningAreas/` — the Calabria warning zone shapefile and all associated files (`.shp`, `.dbf`, `.shx`, `.prj`), required by scripts `01`, `02`, `03`, `11` and `12` in `2_data_preprocessing_and_analysis/`
- `processed/zone_sequence_merged.csv` — the cleaned dataset used for model training and evaluation

---

## What Gets Generated

The remaining files in `processed/` are generated by running the pipeline scripts in `2_data_preprocessing_and_analysis/` in order. See the README in that folder for the full execution guide. This step is optional, since the dataset needed for model training is already included.

The original `.h5` climate and fire target files that feed the pipeline live on a remote server at `../../Calabria_dataset/InputReteGood/`. Scripts that require this dataset are marked with 🖥️ in the preprocessing README and must be run on the remote server after cloning the repo there.
